# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Описание проекта
Аудит качества и разведочный анализ датасета каталога книг books.toscrape.com 
(1000 записей, 12 признаков).

## Структура репозитория
- `books_dataset.csv` — исходные данные
- `notebooks/01_data_understanding.ipynb` — ноутбук с анализом
- `report/quality_report.md` — текстовый отчёт о качестве данных

## Запуск
1. Установить зависимости
2. Запустить Jupyter
